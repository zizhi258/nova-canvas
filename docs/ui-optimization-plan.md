# Nova Canvas UI 优化方案

> 版本：v1.0 · 2026-08-05
> 目标：参考吐司（TusiArt）的「工作台」布局，解决当前页面纵向过长、操作动线不符合直觉、视觉质感不足的问题。

---

## 一、现状诊断

### 1.1 当前结构（`app/page.tsx`）

```
┌──────────────────────────────────────────┐
│ 顶栏 topbar（品牌 / 状态 / 收藏入口）      │
├──────────────────────────────────────────┤
│ 01 连接服务（渠道 / API Key / 文件夹）     │
│ 02 描述画面（画师串 / 正面 / 反向提示词）  │  ← 左列 sidebar-panel
│ 03 生成参数（模型 / 比例 / 步数 / CFG…）   │
│ ┌──────────────────────┐                 │
│ │ 生成按钮 generate-card │               │  ← 右列（窄）
│ └──────────────────────┘                 │
├──────────────────────────────────────────┤
│ 创作结果 image-grid（在页面更下方）        │
├──────────────────────────────────────────┤
│ footer                                   │
└──────────────────────────────────────────┘
         ↓ 整页需要不断上下滚动 ↓
```

### 1.2 核心问题

| # | 问题 | 影响 |
|---|------|------|
| P1 | **整页纵向滚动**：表单在上方、结果在下方，生成后要滚动才能看到图；调参又要滚回去 | 操作动线断裂，「改参数 → 生成 → 看图」循环成本高 |
| P2 | **左列三个大面板堆叠**：连接服务是低频配置，却占据首屏最重要的位置 | 首屏信息过载，高频操作（提示词）被挤到下方 |
| P3 | **生成按钮位置尴尬**：在右窄列中，视口较矮时看不到，且与结果区分离 | 主行动点（CTA）不固定、不醒目 |
| P4 | **结果区与表单区割裂**：图片 grid 在页面底部，与生成动作没有视觉关联 | 缺乏「画布」感，不像创作工具 |
| P5 | **视觉层级平**：面板都是白卡+相同阴影，间距偏大（32px padding），信息密度低 | 显得「网页表单」而非「专业工具」 |

## 二、参考对象：吐司的布局为什么好用

吐司的在线生图页（参考截图）本质是一个 **三区域工作台（Workbench）**：

```
┌────────────────────────────────────────────────┐
│ 顶部细条：模式 Tab（文生图/图生图…）+ 账户/CTA  │  ← 高度很小，纯导航
├──────────────┬─────────────────────────────────┤
│              │                                 │
│   左控制栏    │        右画布 / 结果区          │
│  (固定宽度,   │   (占满剩余空间, 独立滚动)       │
│   独立滚动)   │                                 │
│              │   空状态 = 画布引导              │
│  模型选择     │   有内容 = 图片流                │
│  提示词       │                                 │
│  参数组       │                                 │
│  (可折叠)     │                                 │
│              │                                 │
├──────────────┴─────────────────────────────────┤
│  生成按钮固定在控制栏底部 / 顶部右侧，常驻可见    │
└────────────────────────────────────────────────┘
```

**关键设计点：**

1. **页面本身不滚动** —— `100vh` 锁死，左右两栏各自独立滚动，布局永远稳定；
2. **控制栏固定宽度**（约 300–340px），所有设置收在一处，内部滚动；
3. **结果区占满剩余空间**，图片是主角，第一眼就看到；
4. **生成按钮常驻**（右上角或控制栏底部吸底），任何滚动位置都能点；
5. **低频配置折叠**（高级设置、VAE 等默认收起），控制栏默认只露高频项。

## 三、目标方案：Nova Canvas 工作台布局

### 3.1 新信息架构

```
┌────────────────────────────────────────────────────┐
│ topbar (56px)：品牌 · 状态点 · 收藏 · API Key 状态   │
├─────────────┬──────────────────────────────────────┤
│ 左控制栏     │  右主区（结果画布）                    │
│ 320px 固定   │  ┌────────────────────────────────┐  │
│ ┌─────────┐ │  │ 工具条：视图切换/数量/清空        │  │
│ │① 提示词  │ │  ├────────────────────────────────┤  │
│ │ (默认展开)│ │  │                                │  │
│ ├─────────┤ │  │   image-grid / 空状态引导        │  │
│ │② 参数    │ │  │   (独立滚动)                    │  │
│ │ (默认展开)│ │  │                                │  │
│ ├─────────┤ │  │                                │  │
│ │③ 连接服务│ │  │                                │  │
│ │ (默认折叠)│ │  │                                │  │
│ ├─────────┤ │  │                                │  │
│ │④ 高级设置│ │  │                                │  │
│ │ (默认折叠)│ │  │                                │  │
│ └─────────┘ │  └────────────────────────────────┘  │
│ ┌──────────┐│  ← 左栏独立滚动                       │
│ │ 生成按钮  ││     (吸底，常驻可见)                  │
│ │ + 进度   ││                                       │
│ └──────────┘│                                       │
└─────────────┴──────────────────────────────────────┘
   页面高度 = 100vh，无整页滚动条
```

### 3.2 布局原则

| 原则 | 说明 |
|------|------|
| **页面不滚动** | `html, body { height: 100%; overflow: hidden }`，主区域 `display: flex; height: calc(100vh - 56px)` |
| **左右独立滚动** | 控制栏 `overflow-y: auto`；结果区 `overflow-y: auto`，互不干扰 |
| **生成按钮吸底** | 固定在控制栏底部 `position: sticky; bottom: 0`，进度条、错误提示也在这里 |
| **按使用频率排序** | ① 提示词（每次必改）→ ② 参数（经常调）→ ③ 连接服务（配一次）→ ④ 高级设置（偶尔） |
| **低频默认折叠** | 连接服务、高级设置默认收起为一条 header，点击展开（accordion） |
| **结果是主角** | 结果区占满剩余宽度，空状态时显示引导插画+三步说明 |

### 3.3 各区域详细设计

#### A. 顶栏（56px，精简）
- 左：品牌 Logo（保留现有 brand-mark）
- 中：连接状态点（官方/中转 + Key 已配置✓/未配置）
- 右：画师串收藏入口（保留）、标签超市入口（从表单里移上来）
- 移除现在的 `topbar-note` 长文案，状态用图标+短文字

#### B. 左控制栏（320px，accordion 分区）

**① 提示词区（默认展开，给最多空间）**
- 画师串、正面提示词、反向提示词三个 textarea
- 正面提示词为主，行数从 5 → 4，配合栏高自适应
- 「标签超市」按钮放在正面提示词 label 右侧（就近原则），顶栏也保留一个

**② 生成参数区（默认展开）**
- 模型：保留下拉，或升级为带「推荐」徽标的紧凑下拉
- 画面比例：三宫格按钮保持不变（这个设计已经不错），但压缩高度
- 步数 / CFG：双滑杆可并排成两行，压缩纵向空间

**③ 连接服务区（默认折叠）**
- 折叠时 header 显示状态摘要：`官方渠道 · Key 已配置 ✓` 或 `未配置 Key ⚠`（红/绿状态点）
- 展开后内容不变（渠道切换、Key、记住我、文件夹同步）
- 未配置 Key 时自动展开一次并高亮，配置好后收起

**④ 高级设置区（默认折叠）**
- 采样器、随机种子，保持现有控件

**生成区（吸底）**
- 大按钮「开始生成 / 正在生成…」+ 进度条 + 取消按钮 + 错误提示
- `sticky bottom`，背景带顶部渐变遮罩，滚动时按钮永远可见

#### C. 右主区（结果画布）

- **工具条**（40px）：左「创作结果 · N 张」、视图切换（网格/画师串收藏）、右「清空」
- **空状态**：居中大插画 + 「画布已经准备好了」+ 三步引导（保留现有文案，视觉重做）
- **图片网格**：`grid-template-columns: repeat(auto-fill, minmax(220px, 1fr))`，随宽度自适应 2–5 列
- 画师串收藏视图从「页面下方另一个 section」改为右主区的一种**视图切换**（Tab 或 Segmented Control），不再跳滚

#### D. Lightbox / TagMarket
- 维持现状（已经是模态层，不受布局影响）

### 3.4 视觉规范调整

在现有紫色系（`--purple` 等 CSS 变量）基础上微调，不推翻品牌色：

| 项目 | 现状 | 调整后 |
|------|------|--------|
| 面板 padding | 32px | 16–20px（工具型密度） |
| 面板圆角 | 20px | 12px（更利落） |
| 面板样式 | 白卡 + 阴影 + 边框 | 左栏用浅灰底 `#f7f7f9` 上的白卡，或干脆无卡片、用分隔线分区 |
| section-heading | 大号 01/02/03 序号 + 标题 + 副标题 + 24px 分隔 | 压缩为单行小标题（14px/600），去掉序号（顺序已由位置表达） |
| 控件高度 | 44px+ | 输入框 36–38px，按钮主 CTA 44px |
| 字体层级 | h2 20px | 区标题 14px，控件 label 13px，正文 13–14px |
| 间距节奏 | gap 24–28px | 控制栏内 gap 12–16px |

> 原则：**从「营销页质感」转向「工具质感」** —— 更紧凑、更克制、信息密度更高，但不拥挤。

### 3.5 响应式策略

| 断点 | 行为 |
|------|------|
| ≥ 1024px | 完整双栏工作台（左 320px + 右自适应） |
| 768–1024px | 左栏收窄至 280px，结果区列数减少 |
| < 768px | 左栏变为底部抽屉 / 顶部可展开面板，结果区全宽；生成按钮吸底全宽（移动端优先保证看图体验） |

## 四、实施步骤（改造清单）

> 全部改动集中在 `app/page.tsx`（结构调整）+ `app/globals.css`（样式重写），不动任何生成逻辑、状态管理和 `local-persistence.ts`。

| 步骤 | 内容 | 涉及位置 |
|------|------|----------|
| 1 | 顶层结构改为 `topbar + .workbench{ display:flex; height:calc(100vh-56px) }` | `page.tsx` return 结构 |
| 2 | 三个 panel 改为 accordion 分区组件（受控展开/收起，新增 `openSections` state） | `page.tsx` + 新小组件 |
| 3 | 面板顺序调整：提示词 → 参数 → 连接服务（折叠）→ 高级（折叠并入参数区） | `page.tsx` |
| 4 | generate-card 移入左栏底部，`position: sticky; bottom: 0` | `page.tsx` + CSS |
| 5 | 结果区上移为右主区，加工具条 + 视图切换（结果/收藏两个 view state 替代现有 scrollIntoView 跳转） | `page.tsx` results-section |
| 6 | 空状态视觉重做（居中插画 + 引导） | CSS `.empty-result` |
| 7 | 全局样式密度调整：padding/圆角/字号/控件高度按 3.4 表执行 | `globals.css` |
| 8 | `body { overflow: hidden }` + 双栏 `overflow-y: auto`；自定义滚动条样式（细滚动条） | `globals.css` |
| 9 | 响应式断点落地（重点验证 768px 以下抽屉交互） | `globals.css` |
| 10 | 回归验证：生成流程、进度条、错误提示、lightbox、标签超市、收藏视图、文件夹同步提示 | 手动测试 |

**风险点：**
- `reuseGeneration()` 现在用 `scrollIntoView` 跳到表单 —— 布局改后页面不滚动了，要改为展开对应 accordion 分区（提示词区）即可；
- 收藏视图从滚动跳转改为视图切换后，顶栏「画师串收藏」按钮的行为同步改为切换 view；
- `body overflow: hidden` 会影响 lightbox 现有的 `document.body.style.overflow` 逻辑，需确认不冲突（lightbox 是 fixed 层，理论上无碍）。

## 五、验收标准

1. ✅ 1920×1080 视口下，页面无整页滚动条；调参、生成、看图全程不需要离开当前视口；
2. ✅ 生成按钮在任何滚动位置可见可点；
3. ✅ 连接服务默认折叠且能一眼看到配置状态（绿点/红点）；
4. ✅ 生成结果出现时无需滚动即可看到首图；
5. ✅ 提示词区是控制栏中视觉权重最高的区域；
6. ✅ 768px 以下移动端可用（抽屉/吸底按钮）；
7. ✅ 所有既有功能（生成、取消、收藏、lightbox、标签超市、文件夹同步）无回归。
